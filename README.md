# GREEN-API Web Client (Telegram & MAX Messenger)

> 🌐 **Live Demo (GitHub Pages):** [https://sinonaz.github.io/green-api-chat/](https://sinonaz.github.io/green-api-chat/)  
> 📦 **GitHub Repository:** [https://github.com/Sinonaz/green-api-chat](https://github.com/Sinonaz/green-api-chat)

Веб-клиент в стиле Telegram / MAX Web для отправки и получения текстовых сообщений через **GREEN-API** (с использованием технологии HTTP API).

Поддерживает работу с обоими мессенджерами:
- **Telegram** (через инстансы GREEN-API Telegram)
- **MAX** (через инстансы GREEN-API MAX — [green-api.com/max](https://green-api.com/max))

## 🚀 Стек технологий

- **React 18** + **TypeScript**
- **Vite** (с универсальным dev-прокси для обхода CORS)
- **Tailwind CSS** (стилизация под интерфейс Telegram / MAX Web с динамической темой)
- **Zustand** (с middleware `persist` для сохранения чатов, сообщений и сессии в `localStorage`)
- **Lucide React** (иконки интерфейса)

---

## 📋 Реализованный функционал

1. **Авторизация по учетным данным GREEN-API**:
   - Переключатель мессенджера: **Telegram** / **MAX Messenger**.
   - Ввод `idInstance` и `apiTokenInstance`.
   - Опциональное поле `apiUrl` (хост сервера, по умолчанию `https://api.green-api.com` или персональный выделенный поддомен, например `https://7103.api.green-api.com`).
   - Проверка статуса инстанса методом `getStateInstance` перед входом (с возможностью принудительного входа).
2. **Создание чата**:
   - **По номеру телефона**: обращение к методу `checkAccount`, поиск пользователя в Telegram или MAX и автоматическое определение `chatId`.
   - **По Username / Chat ID**: прямой ввод имени пользователя или числового ID чата.
3. **Отправка текстовых сообщений**:
   - Метод `sendMessage` (`POST /waInstance{idInstance}/sendMessage/{apiTokenInstance}`).
   - Оптимистичное добавление в историю сообщений со статусами: отправка (`sending`), отправлено (`sent`), доставлено (`delivered`), прочитано (`read`), ошибка (`failed`).
4. **Получение входящих сообщений в реальном времени**:
   - Технология **HTTP API** через цикличный Long Polling:
     - Опрос очереди уведомлений методом `ReceiveNotification`.
     - Обработка событий `incomingMessageReceived` и добавление сообщения в нужный чат.
     - Обязательное удаление обработанных уведомлений методом `DeleteNotification` по `receiptId` (освобождение очереди FIFO).
5. **Интерфейс мессенджера**:
   - Левая панель: поиск по чатам и сообщениям, индикатор активности поллинга, бейджи непрочитанных сообщений, аватарки с инициалами.
   - Окно переписки: бабблы сообщений (входящие/исходящие с акцентом под выбранный мессенджер), временные метки, галочки статуса, отправка по `Enter`.
   - Модальное окно настроек: отображение текущего мессенджера, тестирование соединения, смена хоста, очистка истории, выход.

## 🛠 Запуск проекта

### 1. Установка зависимостей (уже выполнен)
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес: [http://localhost:5173](http://localhost:5173).

### 3. Сборка для production
```bash
npm run build
```

## 🧪 Пошаговая инструкция по тестированию

### Шаг 1. Подготовка инстанса GREEN-API (Telegram или MAX)
1. Войдите в личный кабинет на [green-api.com](https://green-api.com).
2. Выберите или создайте ваш инстанс (Telegram или MAX).
3. Скопируйте:
   - `idInstance` (например: `1101823456`)
   - `apiTokenInstance` (токен авторизации)
   - `apiUrl` (если у вас выделенный хост, например `https://7103.api.green-api.com`).
4. Убедитесь, что инстанс авторизован в кабинете GREEN-API.

### Шаг 2. Авторизация в приложении
1. Откройте приложение в браузере ([http://localhost:5173](http://localhost:5173)).
2. Выберите вкладку мессенджера: **Telegram** или **MAX Messenger**.
3. Введите `idInstance` и `apiTokenInstance`.
4. В поле **API URL** укажите ваш выделенный хост (или оставьте пустым, если используется дефолтный `https://api.green-api.com`).
5. Нажмите кнопку **«Подключиться»**.
6. Приложение проверит инстанс через `getStateInstance`, и откроется главный экран чатов с брендированием выбранного мессенджера.
7. В шапке боковой панели загорится индикатор **Live** — это означает, что фоновый сервис Long Polling слушает входящие уведомления.

### Шаг 3. Создание нового диалога
1. В левой панели нажмите на кнопку с иконкой **«+»** (или **«Создать первый чат»**).
2. Выберите способ создания:
   - **Номер телефона**: введите номер получателя в международном формате (например, `79991234567`). Приложение вызовет метод `checkAccount` и получит `chatId` пользователя.
   - **Username / Chat ID**: введите юзернейм или числовой Chat ID.
3. Нажмите **«Создать чат»** — диалог появится в списке чатов слева и откроется в окне переписки справа.

### Шаг 4. Отправка сообщения
1. В правом окне переписки введите в поле ввода текстовое сообщение (например, `Привет! Это тест отправки через GREEN-API`).
2. Нажмите клавишу **Enter** или кнопку отправки.
3. Сообщение появится в чате со статусом отправки, уйдет через метод `sendMessage`, и у него отобразится галочка отправки.
4. Проверьте мессенджер получателя — сообщение поступит в чат.

### Шаг 5. Получение ответа (тест входящих сообщений)
1. С аккаунта получателя отправьте ответ на это сообщение (например: `Привет, ответ получен!`).
2. Фоновый процесс `ReceiveNotification` считает это уведомление из очереди GREEN-API.
3. В чате слева появится входящее сообщение, время отправки и имя отправителя.
4. Приложение автоматически отправит запрос `DeleteNotification` с полученным `receiptId`, подтверждая обработку сообщения.

### Шаг 6. Проверка сохранения состояния (Zustand + localStorage)
1. Обновите страницу в браузере (`Cmd+R` / `F5`).
2. Убедитесь, что сессия сохранилась (не требуется заново вводить ключи), а выбранный мессенджер, чаты и история сообщений остались на месте.
3. Для переключения между инстансами или смены мессенджера нажмите на иконку настроек или выхода.
