# GREEN-API Telegram Web Client

Веб-клиент в стиле Telegram Web для отправки и получения текстовых сообщений через **GREEN-API** (с использованием технологии HTTP API).

## 🚀 Стек технологий

- **React 18** + **TypeScript**
- **Vite** (с dev-прокси для обхода CORS)
- **Tailwind CSS** (стилизация под интерфейс Telegram Web)
- **Zustand** (с middleware `persist` для сохранения чатов, сообщений и сессии в `localStorage`)
- **Lucide React** (иконки Telegram-интерфейса)

---

## 📋 Реализованный функционал

1. **Авторизация по учетным данным GREEN-API**:
   - Ввод `idInstance` и `apiTokenInstance`.
   - Опциональное поле `apiUrl` (хост сервера, по умолчанию `https://api.green-api.com` или персональный поддомен, например `https://7103.api.green-api.com`).
   - Проверка статуса инстанса методом `getStateInstance` перед входом (с возможностью принудительного входа).
2. **Создание чата**:
   - По номеру телефона получателя (с автопоиском `chatId` через метод `checkAccount`).
   - По Telegram username (например, `@username`) или прямому Chat ID.
3. **Отправка текстовых сообщений**:
   - Метод `sendMessage` (`POST /waInstance{idInstance}/sendMessage/{apiTokenInstance}`).
   - Оптимистичное добавление в историю сообщений со статусами: отправка (`sending`), отправлено (`sent`), доставлено (`delivered`), прочитано (`read`), ошибка (`failed`).
4. **Получение входящих сообщений в реальном времени**:
   - Технология **HTTP API** через цикличный Long Polling:
     - Опрос очереди уведомлений методом `ReceiveNotification`.
     - Обработка событий `incomingMessageReceived` и добавление сообщения в нужный чат.
     - Обязательное удаление обработанных уведомлений методом `DeleteNotification` по `receiptId` (освобождение очереди FIFO).
5. **Интерфейс в стиле Telegram Web**:
   - Левая панель: поиск по чатам и сообщениям, индикатор активности поллинга, бейджи непрочитанных сообщений, аватарки с инициалами.
   - Окно переписки: бабблы сообщений (входящие/исходящие), временные метки, галочки статуса, отправка по `Enter`.
   - Модальное окно настроек: тестирование соединения, смена хоста, очистка истории, выход.

## 🛠 Запуск проекта

### 1. Установка зависимостей (уже выполнен)
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес: [http://localhost:5173](http://localhost:5173).

### 3. Сборка для production
```bash
npm run build
```

## 🧪 Пошаговая инструкция по тестированию

### Шаг 1. Подготовка инстанса GREEN-API
1. Войдите в личный кабинет на [green-api.com](https://green-api.com).
2. Перейдите в ваш Telegram-инстанс.
3. Скопируйте:
   - `idInstance` (например: `1101823456`)
   - `apiTokenInstance` (токен авторизации)
   - `apiUrl` (если у вас выделенный хост, например `https://7103.api.green-api.com`).
4. Убедитесь, что инстанс авторизован (связан с вашим Telegram-аккаунтом через QR-код или авторизацию в кабинете GREEN-API).

### Шаг 2. Авторизация в приложении
1. Откройте приложение в браузере ([http://localhost:5173](http://localhost:5173)).
2. Введите `idInstance` и `apiTokenInstance`.
3. В поле **API URL** укажите ваш выделенный хост (или оставьте пустым, если используется дефолтный `https://api.green-api.com`).
4. Нажмите кнопку **«Подключиться к чату»**.
5. Произойдет автоматическая проверка инстанса через `getStateInstance`, и откроется главный экран чатов.
6. В шапке боковой панели появится зелёный индикатор **Live** — это означает, что фоновый сервис Long Polling запущен и слушает входящие уведомления.

### Шаг 3. Создание нового диалога
1. В левой панели нажмите на кнопку с иконкой **«+»** (или **«Создать первый чат»**).
2. Выберите способ создания:
   - **Номер телефона**: введите номер получателя в международном формате (например, `79991234567`). Приложение обратится к методу `checkAccount`, найдет пользователя в Telegram и получит его `chatId`.
   - **Username / Chat ID**: введите юзернейм (например, `durov`) или числовой Chat ID.
3. Нажмите **«Создать чат»**. Диалог появится в списке чатов слева и сразу откроется в правой панели.

### Шаг 4. Отправка сообщения
1. В правом окне переписки введите в поле ввода любое текстовое сообщение (например, `Привет из GREEN-API!`).
2. Нажмите клавишу **Enter** или синюю кнопку с иконкой самолетика.
3. Сообщение появится в чате со статусом отправки, уйдет через метод `sendMessage`, и у него отобразится галочка отправки.
4. Проверьте мессенджер Telegram на телефоне/компьютере получателя — сообщение должно быть доставлено.

### Шаг 5. Получение ответа (тест входящих сообщений)
1. С аккаунта получателя в официальном Telegram ответьте на полученное сообщение (например: `Привет, ответ получен!`).
2. В веб-приложении фоновый процесс `ReceiveNotification` считает это уведомление из очереди GREEN-API.
3. В чате слева появится входящее сообщение (баббл слева), время отправки и имя отправителя.
4. Приложение автоматически отправит запрос `DeleteNotification` с полученным `receiptId`, подтверждая обработку сообщения.

### Шаг 6. Проверка сохранения состояния (Zustand + localStorage)
1. Обновите страницу в браузере (`Cmd+R` / `F5`).
2. Убедитесь, что сессия сохранилась: вам не требуется заново вводить учетные данные, а история созданных чатов и сообщений осталась на месте.
3. Для смены инстанса или сброса истории нажмите на иконку настроек или выхода в боковой панели.
